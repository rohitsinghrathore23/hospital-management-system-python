# Hospital Management System in Python

## Project Overview

This project is a Hospital Management System developed in Python using Object-Oriented Programming (OOP). It manages hospital operations such as patient records and related administrative tasks.

## Features

- Patient Management
- Doctor Management
- Appointment Management
- Record Management
- Menu-Driven Interface

## Technologies Used

- Python
- Object-Oriented Programming (OOP)

## Concepts Used

- Classes and Objects
- Inheritance
- Encapsulation
- Functions
- File Handling (if applicable)

## How to Run

1. Clone the repository.
2. Open the project folder.
3. Run:

```bash
python hospital_management_system.py
```
